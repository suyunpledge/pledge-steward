# 原生化审查记录（2026-11-02）

本次审查的目标是让 Android 端不再启动 Python/FastAPI HTTP 桥或 Python Agent，
并保持已有 Compose、设备工具和 Agent 事件契约。

## 已完成

- `NativeBridgeServer.kt` 在 `127.0.0.1:8000` 提供认证 HTTP 路由和 `/agent/ws`
  WebSocket，使用安装级随机 Bearer token；`/health` 保持免认证。
- 引导、连接器目录、连接器状态、遥控状态、`/capabilities` 和 `/tool/call`
  迁移到 Kotlin，UI 不需要改为 WebView，也不需要 Python HTTP 客户端。
- `NativeAgentEngine.kt` 接管 Agent 核心：provider 配置、OpenAI-compatible 模型
  请求、最多 12 步工具循环、能力快照、取消、设备回执、事件和 JSONL 会话日志。
  模型工具参数在 Kotlin 侧先做 schema/能力/确认校验，DeviceTools 再做一次宿主校验。
- `AgentBridgeService` 直接驱动 NativeAgentEngine；APK 主路径不启动 PRoot、Python、
  FastAPI、Uvicorn 或 stdio Worker。
- Python/PRoot 文件仍保留在仓库，供桌面兼容和历史 rootfs 脚本使用，但不再由 Android
  Service 调用。
- 修复原生 UI HTTP 工具把认证前缀写成字面量 `***` 的问题，统一使用
  `Authorization: Bearer <installation-token>`；这会直接影响引导、目录和遥控页。

## 后端加固（本轮）

- Agent 会把会话名限制为安全字符集，历史消息限制为最近 100 条且最多 120,000
  字符；模型返回的空白或重复工具调用 ID 会在 Kotlin 侧规范化，避免路径穿越、
  无界请求和回执覆盖。
- 取消任务会同时取消 OkHttp 模型请求、挂起的设备回执和运行协程；JSONL 日志写入
  经过单文件串行化并在存储失败时记录告警，不会因为日志故障伪造工具成功。
- 原生桥每个 session 只允许一个 WebSocket；HTTP Content-Length 和 WebSocket 帧均有
  2 MiB 上限，客户端帧必须带掩码，Agent 未就绪时任务和回执接口返回 503。
- 引导配置与连接器状态写入通过进程内锁串行化；远程审批接口在远端协议未实现时返回
  409，不再返回看似成功的占位结果。
- 引导状态会识别 `keyless=true` 或 `127.0.0.1/localhost` 的本地模型端点；Agent 的
  `run_done.steps` 记录实际执行轮数；WebSocket 白名单包含 `tool_result`，桌面或测试
  客户端可以直接回传工具回执。

## 仍需真机验收

- 本机没有可用 JDK/Android SDK 和 adb，因此本轮无法执行 Gradle 编译、APK 安装、
  Kotlin Agent 真机网络请求、Accessibility、Shizuku Binder 和 16 KB page size 验证。
- 遥控状态 API 已迁移状态存储和输入校验；桌面 remote-host 的实际 WebSocket
  配对/审批转发尚未接入原生桥，当前不会把六位数字校验当作远端身份认证。
- 连接器目录和连接器状态已原生化；MCP 子进程工具实际发现/调用尚未接入 Kotlin
  工具注册表，目录安装只保存配置并返回状态，不能当作第三方服务执行能力。
- 截图、UI 树和写操作仍遵循原有 fail-closed 语义：设备回执代表后端回执，
  不代表业务目标完成；`unknown` 结果不能自动重放。

## 审查修复（2026-11-03，Claude）

本机工具链（JDK 17 / Gradle 8.10.2 / SDK 34）编译通过，单元测试 20/20。

- 工具名：模型侧一律用下划线（`android_ui_click`），内部保留点号；OpenAI 兼容接口要求
  `^[a-zA-Z0-9_-]{1,64}$`，带点的名字会让每个请求 400。模型回传两种写法都能映射回来。
- 截图：像素只存设备 `forge-home/captures`（保留最近 5 张），回执只带 `image_file/image_bytes`；
  引擎 `AgentWire.modelReceipt` 另行剔除任何 base64/图片字段、超长文本截到 64k 并标记。
- 首次启动：等桥就绪（最多约 15 秒重试）再判断引导；桥不可达时进引导页，不再误入聊天。
- 联网：Kotlin 版 `web_search` / `fetch_url`（`WebTools.kt`），与桌面 `web_backends.py` 一致：
  中国域 博查→Bing 中国，美国域 Brave→Bing 美国→DuckDuckGo，`region` auto/cn/global/both；
  搜索 Key 取自已安装连接器的 `BOCHA_API_KEY` / `BRAVE_API_KEY`。读网页拒绝本机/内网/链路本地/
  CGNAT 等地址：解析器 + 网络拦截器（IP 字面量和每一跳重定向都检查，发请求前中止），
  放行代理 fake-IP 段 198.18.0.0/15；不走 HTTP 代理（VPN 模式代理可用）。
- 取消：WebSocket 断开只取消本会话的任务；运行事件带 `session` 字段。
- 超时：`TimeoutCancellationException` 先于普通取消捕获；只读工具超时为 `not_started`、任务继续，
  写操作为 `unknown` 并下发 `cancel_tool`。
- 费用：手机端无价格表，`run_done` 不再带 `cost: 0`，UI 只在真有费用时显示。
- 密钥：API Key 与连接器凭据用 Android Keystore AES-GCM 加密存放（`ks1:` 前缀），旧明文可读、
  下次保存即加密。
